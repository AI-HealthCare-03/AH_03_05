# MediPT 건강 프로필 LLM 컨텍스트 구조 정의서
> 작성일: 2026-05-15 | 버전: v1.0

---

## 1. 컨텍스트 삽입 방식

LLM 시스템 프롬프트에 사용자 건강 정보를 구조화하여 삽입한다.
의사 소견은 왜곡 방지를 위해 원문 그대로 삽입한다.
현재 복용약은 사용자 입력이 아닌 식약처 API 검증 완료된
medications 테이블 데이터를 그대로 삽입한다.

---

## 2. 필드별 삽입 방식

| 필드 | 삽입 방식 | 미입력 시 처리 |
|------|-----------|----------------|
| 연령대 | 구조화 | 해당 필드 제외 |
| 성별 | 구조화 | 해당 필드 제외 |
| 기저질환 | 구조화 | 해당 필드 제외 |
| 알레르기 | 구조화 | 해당 필드 제외 |
| 임신/수유 | 구조화 | 해당 필드 제외 |
| 음주 | 구조화 | 해당 필드 제외 |
| 흡연 | 구조화 | 해당 필드 제외 |
| 의사 소견 | 원문 그대로 | 해당 필드 제외 |
| 현재 복용약 | medications 테이블 검증 데이터 | 해당 필드 제외 |

미입력 필드는 프롬프트에서 완전히 제외 (빈 값 삽입 금지)

---

## 3. 현재 복용약 데이터 위치

데이터 출처: medications 테이블 (식약처 API 검증 완료 데이터)

읽어오는 필드:
  drug_name        약품명
  ingredient_name  성분명
  manufacturer     제조사
  dosage           용량
  frequency        복용 횟수
  timing           복용 시점
  caution          주의사항
  side_effect      부작용

삽입 조건:
  is_verified = true
  api_status  = selected

---

## 4. 실제 프롬프트 삽입 포맷

4-1. 건강 프로필 (구조화)

[사용자 건강 정보]
연령대: 40대
성별: 여성
기저질환: 고혈압, 제2형 당뇨
알레르기: 페니실린
임신/수유: 임신 중
음주: 가끔
흡연: 비흡연
의사 소견: 저염식 권고, 유산소 운동 주 3회 이상

4-2. 현재 복용약 (medications 테이블)

[현재 복용약]
1. 암로디핀정 5mg / 암로디핀베실산염 / 동아제약
   용법: 1일 1회 아침 식후
   주의: 자몽주스 병용 금지
   부작용: 두통, 발목 부종

2. 로수바스타틴 10mg / 로수바스타틴칼슘 / 한독
   용법: 1일 1회 저녁 식후
   주의: 고지방식 병용 주의
   부작용: 근육통

4-3. 미입력 필드 예시 (기저질환 미입력 시)

[사용자 건강 정보]
연령대: 40대
성별: 여성
알레르기: 페니실린
(기저질환 미입력 → 필드 자체 제외)

---

## 5. 시스템 프롬프트 삽입 순서

1. 역할 정의
2. 사용자 건강 정보    ← health_profile_context
3. 현재 복용약         ← medications 테이블
4. 출력 규칙 및 형식
5. 금지 사항
