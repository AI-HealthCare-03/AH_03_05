## LLM 프롬프트 활용 기준

### 가이드라인 선택 로직

```python
def select_guideline(disease: str, age: int) -> str:
    if disease in ["고혈압", "I10"]:
        return "GL-002" if age >= 65 else "GL-001"
    elif disease in ["당뇨병", "제2형 당뇨병", "E11"]:
        return "GL-004" if age >= 65 else "GL-003"
    elif disease in ["이상지질혈증", "고지혈증", "E78"]:
        return "GL-005"
    else:
        return None
```

### 프롬프트 삽입 형식

```
[근거 가이드라인]
출처: {organization_name}, {guideline_title} ({published_year})
내용: {guideline_text}
```
