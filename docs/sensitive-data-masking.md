# 민감정보 마스킹 정책

## 개요

MediPT는 의료 문서 업로드 및 AI 분석을 다루는 헬스케어 서비스로, 사용자의 개인정보 및 의료정보가 로그에 노출되지 않도록 마스킹 정책을 적용합니다.

로그 기록 시 민감정보가 평문으로 남을 경우 로그 파일 유출, 모니터링 도구 노출 등의 보안 위협이 발생할 수 있습니다. 이를 방지하기 위해 `MaskingFormatter`를 통해 모든 로그 출력에 자동으로 마스킹을 적용합니다.

### 관련 법령
- **개인정보보호법** — 개인정보의 안전한 관리 의무 (제29조)
- **의료법** — 환자 의료정보 보호 의무 (제19조)

---

## 적용 범위

| 구분 | 내용 |
|---|---|
| 적용 파일 | `app/core/logger.py` |
| 적용 방식 | `MaskingFormatter`를 통해 모든 로그 출력에 자동 적용 |
| 적용 환경 | 개발(로컬) 및 운영(EC2) 환경 동일 적용 |
| 로거 생성 | `setup_logger()`로 생성된 로거 사용 시 전역 자동 적용 |
| 로그 저장 위치 | 콘솔 출력 (stdout) — 운영 환경에서는 nginx 및 Docker 로그로 수집 |

---

## 마스킹 방식

전체 마스킹 방식을 사용합니다. 원본 값을 부분 노출하지 않고 고정 문자열로 완전히 대체합니다.

---

## 현재 마스킹 적용 항목

| 대상 | 패턴 | 마스킹 결과 | 근거 |
|---|---|---|---|
| JWT 토큰 | `eyJ`로 시작하는 토큰 문자열 | `***TOKEN***` | 토큰 탈취 시 인증 우회 가능 |
| 이메일 | `xxx@xxx.xxx` 형식 | `***EMAIL***` | 개인식별정보 (PII) |
| 비밀번호 | `"password": "..."` JSON 필드 | `"password": "***"` | 인증 자격증명 |

---

## 추가 검토 필요 항목

헬스케어 서비스 특성상 아래 항목은 추후 마스킹 적용 검토가 필요합니다.

| 대상 | 이유 | 우선순위 |
|---|---|---|
| FCM 토큰 | 기기 식별 가능한 개인정보 | 중 |
| OCR 추출 텍스트 | 의료 문서 원문 포함 가능 | 높음 |
| 전화번호 | 건강 프로필 입력 시 수집 가능성 | 중 |
| 처방/진단 내용 | 민감 의료정보 해당 | 높음 |

## 마스킹 검증

`app/core/logger.py` 마스킹 동작은 `app/tests/core/test_smtp.py` 및 로거 단위 테스트를 통해 검증합니다.

마스킹 정상 동작 확인 방법:
```python
from app.core.logger import mask_sensitive

assert "***TOKEN***" in mask_sensitive("eyJhbGciOiJIUzI1NiJ9.test.test")
assert "***EMAIL***" in mask_sensitive("user@example.com")
assert "***" in mask_sensitive('"password": "mypassword"')
```
