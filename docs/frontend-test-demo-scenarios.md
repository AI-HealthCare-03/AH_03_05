# 프론트엔드 시연 영상 시나리오

데모데이 시연 영상(walkthrough)의 화면 흐름과 촬영 가이드. 실제 구현은 `frontend/e2e/demo/demo.spec.ts`.

---

## 실행 / 녹화

- 위치: `frontend/e2e/demo/demo.spec.ts` (`test('시연: 핵심 플로우 walkthrough')`)
- 설정: `frontend/playwright.demo.config.ts` (영상 녹화 on, slowMo 350, 1280×800)
- 실데이터 기준(모킹 없음). 로컬 dev(최신 코드) 또는 prod 대상. 자격증명은 런타임 env로만 주입(커밋에 값 미포함):
  ```
  # 로컬 dev(최신 코드, baseURL 기본값 localhost:8081):
  DEMO_EMAIL=... DEMO_PASSWORD=... npx playwright test --config playwright.demo.config.ts
  # prod 대상:
  DEMO_EMAIL=... DEMO_PASSWORD=... PLAYWRIGHT_BASE_URL=https://medipt05.store \
    npx playwright test --config playwright.demo.config.ts
  ```
- 영상 가독성: 시각 커서 주입 + 클릭 전 마우스 애니메이션 이동 + 하단/사이드 네비 클릭으로 자연스러운 전환.
- 로그인 외 각 섹션은 `section()`으로 감싸 데이터 유무·실패에도 투어가 끊기지 않음.

---

## 시연 범위

- **본 시연 흐름**: 로그인 → 온보딩 → 홈 → 진료기록 → 복약 가이드 → 건강상담
- **제외**: 회원가입 (시연 영상에 넣지 않음). 로그인은 폼 제출만 짧게 노출. OCR 업로드는 결과 매핑 버그로 제외(아래 제약 참고).

## 시연 흐름

1. **로그인** — 자격증명 입력 → 제출. (가입 화면은 영상에 넣지 않음)
2. **온보딩(건강 프로필)** — 프로필 미입력 계정이라 로그인 직후 **자동으로 온보딩에 안착**.
   - STEP 1(연령대·성별) 화면 노출 → "건강 정보를 입력하면 개인화 가이드를 받는다"를 설명.
   - 저장 없이 **"건너뛰고 둘러보기"로 홈 진입**.
3. **홈 대시보드** — 짧게 노출(스크롤 없이 길게 멈추지 않음).
4. **진료기록 (목록 → 상세)**
   - "진료기록" → 기록 카드를 **실제로 클릭(커서 이동 모션)** → 상세에서 약품(암로디핀·메트포르민)·복용법 노출.
5. **복약 가이드**
   - 진료기록 상세의 **"가이드" 버튼**으로 진입 → "💊 복약 안내" → "🚶 생활습관" 탭 전환.
   - 카드: 섹션별 단일 카드(항목 행+구분선), 아이콘(알약/경고삼각형/러닝/하트) + 제목 + 본문, WARNING 카드/배너.
6. **건강상담 (라이브 채팅) — 핵심 차별점**
   - 가이드 화면의 **"건강상담에 물어보기" 버튼**으로 진입(guide_id 컨텍스트 주입 #232).
   - 본인 약을 알아야 답할 수 있는 질문: **"암로디핀이랑 같이 먹으면 안 되는 거 있어요?"**
   - 챗봇이 개인 가이드(암로디핀)를 참조해 답하는 것이 화면으로 증명됨 → 일반 ChatGPT와의 차별점.

## 데이터 전제 (시드 계정)
- **프로필 미입력**(→ 로그인 시 온보딩 자동 노출) + **가이드 보유 기록**(암로디핀·메트포르민 + 생성된 가이드).
- 직접입력(수동 기록)으로 약품을 넣으면 "인식된 약품 (N종)"에 각 약품이 "직접 입력" 배지로 표시됨(검증 완료).
- 시연 전 약품 표시·가이드 생성·챗봇 개인 답변이 기대대로인지 prod에서 점검할 것.

## 범위 / 알려진 제약
- **OCR 업로드**: 결과 매핑 BE 버그(`_classify_line_type` "정/mg" 과매칭 → "처방 의사"·"1 정"·"의사 서명" 등
  비-약품 라인이 약품으로 인식, prod 실측)로 **시연에서 제외**. 시드 기록(직접입력)으로 대체.
  BE 분류 수정 후 OCR 업로드→결과 풀 시연으로 확장 가능.
- **가이드 → 챗봇 컨텍스트**: PR #241(guide_id 주입) 머지됨. "건강상담에 물어보기" 버튼으로 진입 시
  세션에 guide_id가 실려 챗봇이 개인 가이드를 참조. (prod 배포 반영 필요)
- **원본 이미지 미리보기**: file_url 미채움(BE, 데모데이 이후)으로 플레이스홀더 표시.

## OCR 풀 시연 전환 조건 (데모데이 전 BE 수정 시)
- BE `_classify_line_type` 분류 강화(또는 LLM 추출)로 약품 결과가 정상화되면,
  홈과 진료기록 사이에 **OCR 업로드 → 분석 완료 → 약품 인식 결과(정상)** 섹션을 추가해 풀 시연으로 확장.
