# 프론트엔드 시연 영상 시나리오

데모데이 시연 영상(walkthrough)의 화면 흐름과 촬영 가이드. 실제 구현은 `frontend/e2e/demo/demo.spec.ts`.

---

## 실행 / 녹화

- 위치: `frontend/e2e/demo/demo.spec.ts` (`test('시연: 핵심 플로우 walkthrough')`)
- 설정: `frontend/playwright.demo.config.ts` (영상 녹화 on, slowMo 350, 1280×800)
- 실데이터 기준(모킹 없음). 로컬 dev(최신 코드) 또는 prod 대상. 자격증명은 런타임 env로만 주입(커밋에 값 미포함):
  ```
  # 로컬 dev(최신 코드, baseURL 기본값 localhost:8081):
  DEMO_EMAIL=... DEMO_PASSWORD=... npx playwright test --config playwright.demo.config.ts
  # prod 대상:
  DEMO_EMAIL=... DEMO_PASSWORD=... PLAYWRIGHT_BASE_URL=https://medipt05.store \
    npx playwright test --config playwright.demo.config.ts
  ```
- 영상 가독성: 시각 커서 주입 + 클릭 전 마우스 애니메이션 이동 + 하단/사이드 네비 클릭으로 자연스러운 전환.
- 로그인 외 각 섹션은 `section()`으로 감싸 데이터 유무·실패에도 투어가 끊기지 않음.

## 전제 (데모 계정 seed)
- 약품(암로디핀·메트포르민) + **생성된 가이드가 있는 기록**(record 1 — guide_id 연결).
- 가이드 화면은 guideId 없이 탭 진입 시 빈 화면이므로, 반드시 **진료기록 상세의 "가이드" 버튼**으로 진입.
- 온보딩: 데모 계정은 프로필이 있어 자동으로 홈에 가므로 `/onboarding` 직접 진입으로 화면만 노출(저장 없이 건너뜀).

---

## 시연 범위

- **본 시연 흐름**: 로그인 → 온보딩 → 홈 → OCR 업로드 → 진료기록 → 복약 가이드 → 건강상담
- **제외**: 회원가입 (시연 영상에 넣지 않음). 로그인은 폼 제출만 짧게 노출.

> OCR 파이프라인은 prod에서 작동(업로드→처리 완료)하나, 약품 결과 매핑에 비-약품 라인이
> 섞이는 BE 버그가 있어(`_classify_line_type` 과매칭, BE 공유됨),
> **업로드 모달까지만 노출**하고 약품 결과는 미리 정리된 seed 기록으로 보여준다.
> BE 분류 수정 후에는 C안(OCR 풀 시연)으로 전환.

## 시연 흐름 (B안 — OCR 업로드 장면 포함)

1. **로그인** — 자격증명 입력 → 제출. (가입 화면은 영상에 넣지 않음)
2. **온보딩(건강 프로필)** — 로그인 직후, 홈 진입 전에 노출.
   - `/onboarding` STEP 1(연령대·성별) 화면을 보여주고 "건강 정보를 입력하면 개인화 가이드를 받는다"를 설명.
   - 데모 계정은 프로필이 있어 **저장 없이 "건너뛰고 둘러보기"로 홈 진입**(프로필 데이터 변경 방지).
3. **홈 대시보드** — 복약 달성률·최근 상담 카드, 고혈압 관리 칩 노출.
4. **OCR 처방전 업로드 (장면만)**
   - "의료 문서 업로드" → 업로드 모달(처방전/약봉투/진료기록 탭 + 사진촬영·갤러리) 노출 → 닫기.
   - ⚠️ 약품 인식 결과 화면은 매핑 버그(비-약품 라인 혼입)로 **스킵**. 결과는 5단계의 seed 기록으로 대체.
5. **진료기록 (상세 → 약품)**
   - "진료기록" → 가이드 보유 기록(record 1) 상세 → 약품(암로디핀·메트포르민)·복용법 노출.
6. **복약 가이드**
   - 진료기록 상세의 **"가이드" 버튼**으로 진입 → "💊 복약 안내" → "🚶 생활습관" 탭 전환.
   - 카드: 섹션별 단일 카드(항목 행+구분선), 아이콘(알약/경고삼각형/러닝/하트) + 제목 + 본문, WARNING 카드/배너.
7. **건강상담 (라이브 채팅)**
   - "건강상담" → "새 상담" → 질문 입력("혈압약 복용 시 주의할 점이 있나요?" — 가이드 약품과 일치) → 전송(Enter) →
     내 질문 버블 → 라이브 AI 답변(별점 노출을 "답변 도착" 신호로 사용).

## 범위 / 알려진 제약
- **OCR 약품 결과 매핑 버그(BE)**: `_classify_line_type`이 "정/mg" substring 과매칭 → "처방 의사", "1 정",
  "의사 서명" 등 비-약품 라인이 약품으로 인식됨(prod 실측). 수정 전까지 결과 화면은 시연 제외.
- **가이드 → 챗봇 컨텍스트**: PR #241(guide_id 주입) 머지됨. prod 배포 반영 후 "건강상담에 물어보기"로
  가이드 맥락 전달 가능. 시연은 안정성을 위해 건강상담 탭 직접 진입 사용.
- **원본 이미지 미리보기**: file_url 미채움(BE, 데모데이 이후)으로 플레이스홀더 표시.

## C안 전환 조건 (데모데이 전 BE 수정 시)
- BE `_classify_line_type` 분류 강화(또는 LLM 추출)로 약품 결과가 정상화되면,
  3단계를 **업로드 → 분석 완료 → 약품 인식 결과(정상)** 까지 풀 시연으로 확장.
