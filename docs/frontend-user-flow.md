# 프론트엔드 사용자 흐름

> 2026-06-15 · 조이레

## 핵심 플로우

**회원가입**
로그인 → 회원가입 → 이메일 인증 → 약관 동의 → 온보딩(건강정보) → 홈

**의료 문서 업로드 → 가이드 생성** (메인 플로우)
홈/기록 → 업로드 모달 → OCR 처리 중 → OCR 결과 확인 → 약품 후보 선택 → 가이드 생성 중 → 가이드 결과
> OCR·가이드 "처리 중" 화면은 잡 폴링으로 BE 실제 progress를 반영하고, 미연동 시 자체 진행 표시로 폴백

**챗봇 상담**
챗봇 목록 → 새 상담 or 기존 세션 → 챗봇 대화
가이드 결과 → 챗봇 질문하기 → 챗봇 대화

**진료기록 조회**
기록 목록 → 기록 상세 → 약품 상세 or 가이드 결과

**설정**
설정 → 건강정보 수정 · 비밀번호 변경 · 알림 설정 · 기기 관리 · 약관 동의 · 회원탈퇴

**알림 딥링크**
알림 목록 → 가이드 완료 알림 → 가이드 결과 / OCR 완료 알림 → OCR 결과

## 접근 단계

| 기능 | 단계 |
|------|------|
| 홈 | 1 |
| 챗봇 · 진료기록 상세 · 건강정보 수정 | 2 |
| 업로드 → OCR → 가이드 | 6 |

## 에러 처리

| 상황 | 처리 |
|------|------|
| 로그인 5회 실패 | 계정 잠금 안내 |
| OCR · 가이드 생성 실패/타임아웃 | 실패 화면 + 재시도 |
| 파일 형식 오류 · 10MB 초과 | 업로드 모달 인라인 에러 |

| 인증 만료 | 자동 갱신 → 실패 시 로그인 이동 |
| 챗봇 안전 응답 | ⚠️ 강조 말풍선 |
